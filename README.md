# 保險工具人｜Insurance Toolman

把複雜的保險，變成你自己能用的工具。

## 網站入口（給客戶看的網頁）

https://michaelg-glitch.github.io/insurance-toolman/

## 三個入口

- **實用工具**（`tools/`）：強制險申請通用版等自助手冊
- **保險觀念**（`learn/`）：車禍、汽車保險、人壽保險
- **常見問答**（`qa/`）：客戶常見問題整理

## 如何管理

這個儲存庫存放的是網站「原始檔案」。修改並提交後，GitHub Pages 會自動重新發佈，約 1～2 分鐘後網站更新。

- 新增／更新工具：把 HTML 放進 `tools/` 對應資料夾
- 新增／更新觀念：把 HTML 放進 `learn/` 對應資料夾
- 更新問答：編輯 `qa/index.html`
